# Языковые пакеты Moonrise

Количество пользовательских языков не ограничено. Каждый язык — отдельный UTF-8 JSON-файл; эти файлы можно хранить в отдельном репозитории переводов.

1. В Moonrise откройте **Настройки → Языковые пакеты → Открыть папку**.
2. Скопируйте `en.template.json` в `my-language.moonrise-language.json`.
3. Измените `code`, `name` и значения в `translations`. Английские ключи оставьте как есть.
4. Вернитесь в Moonrise. Язык появится в настройках и меню в шапке без перезапуска.

```json
{
  "schemaVersion": 1,
  "code": "de",
  "name": "Deutsch",
  "translations": {
    "Home": "Startseite",
    "Launch": "Starten",
    "{0} enabled": "{0} aktiviert"
  }
}
```

Код может содержать регион и письменность: `pt-BR`, `zh-Hans`, `sr-Latn-RS`.
Сохраняйте подстановки `{0}`, `{1}` и переводы строк `\n`. Пустые переводы, неверные метаданные и повреждённый JSON отклоняются; причина отображается в диагностике. Остальные языки продолжают работать.

Отсутствующие строки показываются на английском, для `ru` — на встроенном русском. Пользовательский файл имеет приоритет над встроенным языком с тем же кодом. При нескольких файлах с одинаковым кодом применяется последний в алфавитном порядке имён файлов.

Папка установленного приложения: `%LOCALAPPDATA%\Moonrise\settings\language-packs`. При запуске из исходников данные находятся внутри `%LOCALAPPDATA%\Moonrise\dev`. Кнопка в настройках всегда открывает нужную папку.

Встроены русский и английский, а также начальные переводы основных элементов интерфейса на украинский, немецкий, французский, испанский, португальский (Бразилия), польский, турецкий, китайский (упрощённый), японский и корейский. Дополнительные десять пакетов пока частичные: подсказки и диагностические сообщения могут оставаться на английском. Их можно дополнять по шаблону; это не заявка на полную локализацию.

Для разработчиков: `python tools/export-language-templates.py` обновляет шаблоны из статических вызовов `T` в интерфейсе. Интерполированные диагностические сообщения пока не входят в файловый словарь. Добавляйте новые динамические строки через `string.Format(T("…{0}", "…{0}"), value)`.
