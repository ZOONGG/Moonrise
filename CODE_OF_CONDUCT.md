# Code of conduct

Moonrise is committed to a welcoming, professional, and harassment-free community.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and code without attacking people.
- Give actionable feedback and accept correction in good faith.
- Respect privacy, licenses, trademarks, and security boundaries.
- Help keep issues and pull requests focused and safe for a public repository.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, deliberate intimidation, doxxing, credential sharing, piracy, or publishing another person's private data or proprietary files is not accepted. Repeated disruption, bad-faith arguments, and attempts to bypass client authentication or security controls are also outside this project's scope.

## Enforcement

Report conduct concerns privately to the maintainers through the repository's Security reporting channel when possible. Maintainers may edit or remove content, close contributions, issue warnings, or temporarily or permanently restrict participation. Reports will be handled as privately and fairly as practical.

This code applies in repository spaces and when a person is publicly representing the Moonrise project.
